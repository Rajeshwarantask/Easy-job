CONFIDENCE THRESHOLD EXPLAINED:
═════════════════════════════════════════════════════════════════════════════

Each pattern match in subject = weight 2
Each pattern match in body = weight 1

Example 1: "Your profile remains under review"
  - Matches 1 application pattern (subject) = weight 2
  - Score: 2.0
  - Before: 2.0 >= MIN_CONFIDENCE(2.0) → ACCEPTED ✓
  - After:  2.0 >= MIN_CONFIDENCE(1.5) → ACCEPTED ✓

Example 2: Generic recruiter email "Thanks for your interest"
  - Matches 1 application pattern (body) = weight 1
  - Score: 1.0
  - Before: 1.0 >= MIN_CONFIDENCE(2.0) → REJECTED ✗
  - After:  1.0 >= MIN_CONFIDENCE(1.5) → REJECTED ✗
  - BUT:    Domain is careers@ → Auto boost to 2.5 → ACCEPTED ✓
