[v0-AI-PARSER-RAW]
├─ Shows: What Claude extracted BEFORE processing
├─ company_raw: The raw company value Claude returned
├─ status_raw: The raw status Claude classified
└─ Look for: Garbage in company_raw or always "applied" in status_raw

[v0-AI-PARSER-FINAL]
├─ Shows: What AI parser returns AFTER processing
├─ company: Final company (after "Unknown Company" fallback)
├─ eventType: Final status (after mapping)
└─ Look for: Matches raw if AI was good, differs if fallback kicked in

[v0-REGEX-FALLBACK]
├─ Shows: When regex is used instead of AI
├─ company: Regex-extracted company
├─ eventType: Regex-classified status
└─ Look for: If present = AI failed; if garbage = regex is culprit

[v0-STAGE-DEBUG]
├─ Shows: All events grouped for one application
├─ event_types: ["applied", "interview", "offer", ...] (all for company)
├─ last_event_type: Most recent email status
└─ Look for: If all "applied" = AI classified everything as applied

[v0-STAGE-ASSIGNED]
├─ Shows: Final stage calculated
├─ last_event_type: Last email's eventType
├─ final_status: Resulting stage ("applied", "interview", "offer", etc)
└─ Look for: If mismatch (e.g., last="offer" but final="applied") = mapping bug
