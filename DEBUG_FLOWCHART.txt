BUG 1: ALL APPLICATIONS STUCK AT "APPLIED"
─────────────────────────────────────────────────────────────────────────────

Step 1: Check [v0-STAGE-DEBUG] logs
        What are the event_types for each application?

        CASE A: event_types: ["applied", "applied", "applied"]
                └─ Events are homogeneous (all applied)
                └─ ROOT CAUSE: AI parser classifying everything as "applied"
                └─ FIX NEEDED: Rewrite AI prompt for better signal detection
                └─ Check: [v0-AI-PARSER-RAW] — is status_raw always "applied"?

        CASE B: event_types: ["applied", "interview", "offer"]
                └─ Events are diverse
                └─ Go to Step 2

Step 2: Check [v0-STAGE-ASSIGNED] logs
        Is final_status matching last_event_type?

        CASE B1: last_event_type: "offer", final_status: "offer" ✓
                 └─ Everything working correctly
                 └─ BUG might be cache or display issue

        CASE B2: last_event_type: "offer", final_status: "applied" ✗
                 └─ statusMap not mapping correctly
                 └─ ROOT CAUSE: application-resolver.ts line ~113
                 └─ FIX NEEDED: Check statusMap dictionary

WHAT EACH DEBUG LOG MEANS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[v0-AI-PARSER-RAW]
  ├─ subject: Email subject (first 80 chars)
  ├─ is_job_related: true/false (is this recruitment email?)
  ├─ company_raw: What Claude extracted
  ├─ status_raw: What Claude classified (applied/interview/offer/rejected/etc)
  └─ confidence scores and reasoning

[v0-AI-PARSER-FINAL]
  ├─ subject: Email subject
  ├─ company: Final company (after "Unknown" fallback)
  ├─ eventType: Final status (after mapping)
  └─ role: Job title (if found)

[v0-REGEX-FALLBACK]
  ├─ subject: Email subject
  ├─ from: Sender email
  ├─ company: Regex-extracted company
  ├─ eventType: Regex-classified status
  └─ Shows: When regex is used instead of AI

[v0-STAGE-DEBUG]
  ├─ company: Company name
  ├─ role: Job title
  ├─ total_emails: How many emails for this company
  ├─ event_types: Array of all eventTypes (["applied", "interview", ...])
  └─ last_event_type: Most recent email's type

[v0-STAGE-ASSIGNED]
  ├─ company: Company name
  ├─ last_email_eventType: Type of last email
  ├─ final_status: Resulting application status
  └─ mapped_correctly: Boolean showing if mapping worked
