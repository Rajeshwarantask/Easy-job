================================================================================
                         HOW TO USE THIS
================================================================================

ADDING NEW ATS SUPPORT:

1. Create strategy:
   class WorkdayExtractionStrategy extends BaseExtractionStrategy {
     platformId = "workday";
     canHandle(context) { /* detect Workday emails */ }
     extract(context) { /* extract from Workday template */ }
   }

2. Register:
   registry.register(new WorkdayExtractionStrategy());

3. Done! Pipeline automatically uses it.

---

UPDATING EXTRACTION RULES:

1. Edit rule-registry.ts
2. Add/update rule in COMPANY_EXTRACTION_RULES, etc.
3. Deploy
4. Done! New rules take effect immediately.

---

DISABLING A STAGE:

1. Edit pipeline-config.ts
2. Set enabled: false for that stage
3. Deploy
4. Done! Pipeline skips it.

---

TESTING A STAGE:

1. Import test utilities:
   import { createTestContext, testStage, TEST_EMAILS } from "./__tests__/test-utils";

2. Test:
   const context = createTestContext(TEST_EMAILS.indeedConfirmation);
   const result = await metadataExtractor.execute(context);
   assert(result.success);

3. No Gmail API needed. No databases. Just JSON.
