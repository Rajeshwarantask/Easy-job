COMPREHENSIVE EMAIL PARSING LOGGING
====================================

How to view logs:
1. Run: pnpm dev
2. Open browser DevTools (F12)
3. Click "Sync Gmail" button
4. Watch console for detailed trace of each email

LOG SECTIONS
============

[FETCH]
Shows how many emails were retrieved from Gmail

[EMAIL #N]
Each email gets its own collapsible section

Stages logged per email:
1. Email Fetched ✓
2. HTML Cleaning - Removes HTML tags, extracts plain text
3. Blocklist Check - Verifies sender isn't blocked
4. AI Processing - Claude extracts company/role/status
5. Final Merge - Combines AI + regex results
6. Final Parsed Object - The complete extracted data


CONFIDENCE SCORES
================

Company: 0-100%
  - 100% = Explicitly found in subject/body
  - 70% = Found in signature
  - 40% = Inferred from context
  - 10% = Not found, using placeholder

Job: 0-100%
  - Based on how clearly the role is stated

Status: 0-100%
  - 100% = Clear status signal (offer, rejection, etc)
  - 70% = Moderate signal
  - 40% = Weak signal
  - 10% = Ambiguous

FINDING ISSUES
==============

1. Email shows company: "Unknown Company"?
   → Look at [AI Processing] section
   → Check if AI found real company or marked as low confidence

2. Status always "Applied"?
   → Watch [AI Processing] for status_raw value
   → Check if regex fallback was used instead

3. Email skipped?
   → Look for ⊘ (skip status)
   → Check reason (not job-related, low confidence, blocked sender)

4. Slow processing?
   → Look at timing info
   → AI Processing typically takes 1000-3000ms per email
   → Other stages are <50ms
