WHAT TO LOOK FOR IN OUTPUT:
═══════════════════════════════════════════════════════════════════

Three key numbers that tell you WHERE the problem is:

Number 1: Parsed Emails count
  - Should be 60-90% of Job Emails
  - If too low (e.g., 7 when should be 250): PARSER IS BROKEN

Number 2: Applications (before fuzzy) count
  - Should be 30-80% of Parsed Emails
  - Result of grouping emails by (company, role)

Number 3: Applications Created count
  - This is what dashboard displays
  - If Parsed >> Created: RESOLVER IS BROKEN
